> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the backend P0 loop by integrating DashScope Qwen into the RAG workflow, adding retrieval retry, and validating `chroma` mode end-to-end.

**Architecture:** Keep the current Spring Boot, LangChain4j embeddings, and LangGraph4j workflow structure. Add a thin DashScope client plus workflow configuration, then refactor the workflow to own retrieval and retry decisions instead of consuming a single precomputed source list.

**Tech Stack:** Spring Boot 3.3, Java 17, Maven, LangChain4j, LangGraph4j, MockMvc, JUnit 5
